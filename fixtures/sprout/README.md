# Sprout

A plant-care journal that works offline. Your plants, photos and notes live on your device; syncing between devices comes later.

A React web app you can install, with its data in the browser's own database (IndexedDB, through Dexie). It can identify a plant from a photo using a plant identification service.

> This is a fixture: a small, made-up project that Peer AI's evals review. It has problems planted on purpose, and it is not a real product.
