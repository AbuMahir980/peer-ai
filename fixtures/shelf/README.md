# Shelf

Borrow books from neighbours, and lend yours.

A React Native app built with Expo. It's in production and being rebuilt one feature at a time: the older screens in `src/legacy/` are JavaScript with Redux, and the newer features in `src/features/` are TypeScript with hooks. The API lives in another repository.

> This is a fixture: a small, made-up project that Peer AI's evals review. It has problems planted on purpose, and it is not a real product.
