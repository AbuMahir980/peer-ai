Add the qa-acceptance skill. It checks a built work item as a tester would, before it ships: each acceptance criterion followed through the code with its own values and at its edges, each refusal it lists, and whose data it protects; each proven by a test that would fail if the code were wrong; and nothing built that the item didn't ask for. Each criterion gets its own line in the report.
