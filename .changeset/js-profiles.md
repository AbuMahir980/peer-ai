Seven more stack profiles: Node, React, React Native, Next.js, Express, NestJS and Fastify. Each rule carries out a core rule; the automatic ones, such as hooks called the same way on every render, no HTML from outside, images with alt text, text that follows the person's size and nothing written to a phone's device log, are each run through ESLint on an example that must fail and one that must pass. Express's layering rules apply only to a part that declares its architecture, layered or modular monolith. The ESLint plugins the profiles use are optional peer dependencies, loaded only when a listed profile needs one, and every rule runs under a name Peer AI owns, such as `peer-ai-jsx-a11y/alt-text`, so it never clashes with the project's own plugins or settings.
