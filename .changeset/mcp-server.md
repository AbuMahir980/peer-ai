Add the MCP server, `peer-ai mcp`. Any AI tool that supports MCP reaches the same project map, work items and gates through eight tools: `project_map`, `next_work`, `standards_for_file`, `create_work_item`, `update_work_item`, `run_verify`, `record_review` and `advance_work_item`. Moving a work item to ship or done passes the same gates as `peer-ai check`, and only `run_verify` records a verify, by running the project's own command.
