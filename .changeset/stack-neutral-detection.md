Treat every stack as fully as Python. `assess` finds personal and card data in camelCase names (`phoneNumber`, `dateOfBirth`, `IPAddress`), not only snake_case, and reads the model and migration files of any language's ORM. It recognises .NET, Swift and Elixir projects; backend frameworks in Go, Rust, Ruby, PHP, Kotlin and Swift; any Ruby or PHP project, not only Rails and Laravel; and Go and Cargo workspaces. It reads the project's name from Cargo, Go, Composer, pubspec and Gradle files; finds tests, lint configs, dependency files and monitoring libraries across these languages; and skips their build folders. Rule and schema examples now show camelCase beside snake_case.
