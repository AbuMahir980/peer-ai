Add the release-readiness skill. Before a release reaches production, it checks every item in it passed its own gates (a passing verify, every required review, every acceptance criterion), the release goes out through the pipeline with checks that can stop it, every step can be undone and data changes run in a safe order, interfaces others use keep working, the release was tried in staging, scanned and penetration-tested in time, and there are backups, alerts, health checks and an incident plan.
