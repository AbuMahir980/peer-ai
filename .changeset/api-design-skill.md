Add the api-design skill. It designs or updates an API with its contract as the one source of truth: who may call each endpoint and for which records, typed requests and responses, one error shape, paged lists, money in the smallest unit, idempotency keys for anything that can't be repeated, and changes that add, migrate, then remove. It finds where the code and the contract disagree, and writes a change to another repository's API as a request to its owners.
