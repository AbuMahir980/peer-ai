requirements-analysis keeps every existing requirement when it updates a document: a requirement the code doesn't meet yet is a gap to report, never a reason to weaken it. It also compares the code with the requirements both ways, and asks about features the code has that nobody wrote down. An extra idea added to a request stays out of the agreed scope until someone decides. All three came from its first evals.
