Add the system-design skill. It designs how one feature is built across the system before anyone writes it: which parts change, each journey's flow with its permission checks, the data and API changes, and the hard cases (two people at once, a request done twice, a call that fails, data that must not be lost), with the tests that prove each. A part in another repository gets a contract request, not a design of its insides.
