Add the architecture skill. It writes or updates the architecture: the parts, what each owns, how they may depend on each other, where data lives, the contracts between them, and where they run, stated concretely enough for code review to check every change against it. Each significant choice gets a decision record with its options, proposed until a person decides. Where the code breaks the architecture, the break is reported, never written in as the new rule.
